The vision

More than a chat window.
A place to work with AI.

We're building Zirak AI as a desktop environment where users can work with different local models, organize conversations, explore documents, and gradually access a wider set of useful tools — without being tied to a single model provider.

◈

Model freedom

Choose from compatible Ollama models and use different models for different tasks. Model compatibility, hardware needs, and licences will be clearly documented.

⌂

Local-first direction

Local inference is central to the product vision. Users should understand where processing happens and when an optional network feature is enabled.

▤

Practical workspace

Bring AI chat, document workflows, spreadsheets, notes, and productivity features into a coherent desktop experience.

The model ecosystem

One application.
More room to choose.

Today's model work starts with DeepSeek-R1 1.5B. The longer-term goal is to let users discover, add, manage, and switch between compatible downloadable models from inside Zirak AI.

Product family · Planned editions

Different needs.
A clear edition for each.

The product family is being planned as separate editions with distinct capabilities, installers, licences, and deployment expectations. Availability will be announced only when each edition is ready.
